# 🎬 CineBook — Genre API

> 🎥 A simple and structured Movie Genre REST API built with Node.js and Express.js.

CineBook is a movie-based backend application that provides RESTful APIs for managing movie genres. The project follows the MVC architecture and demonstrates how routes, controllers, and data can work together to build a clean Express.js API.

---

## ✨ Project Overview

CineBook allows users to:

- 🎭 View all available movie genres
- 🔎 Search for a genre using its ID
- ➕ Add a new movie genre
- 🎞️ Store classic movies associated with each genre
- 🚀 Access the functionality through REST API endpoints
- 🧩 Follow a simple MVC-based structure
